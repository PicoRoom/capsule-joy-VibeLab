# Enamel UI illustrations

Generated with the built-in image_gen tool on 2026-11-10 for Capsule Joy. These six PNG tiles are restored unchanged from the previous Unity project's `Assets/UI/Art`. Original RGBA alpha is preserved. `CapsuleArtBuilder` places full-UV textures on world-space meshes using standard transparent URP Lit materials; no Canvas or runtime UV cropping is required. Tutorial stages select static illustration objects by visibility.

Prompt: A transparent 3×2 sprite sheet of six isolated tactile enamel objects: mint/ivory capsule with leaf and brass seam; miniature collectible shelf; brass/teal gear; ivory hand pinching a copper coin; teal/ivory storage box; three collectibles on a small display stand. Refined ceramic and satin enamel, coherent soft upper-left lighting, readable silhouettes, wide transparent padding, no text, frames, background, or UI mockup. Landscape 1536×1024.

Role: decorative and action-identifying artwork only. Inventory previews always use the actual collected 3D toy. Undiscovered slots have no model or artwork.

## Visual roles in the AR interface

- Identity: capsule emblem, dark enamel sign, thin brass trim.
- Primary action: warm brass button with a visible lower edge and press feedback.
- Tools: inset teal buttons with individual shelf/gear/hand/storage/display illustrations.
- Navigation: small circular brass keys, separate from the series nameplate.
- Settings: compact slider-style switches with an explicit on/off label.
- Collection: thin shelf-edge nameplates; collected entries use ivory, undiscovered entries use muted teal and text only.
- Instructions: dark hand-action note; mechanism observation uses an ivory technical note with a gear illustration.

No icon is used as an undiscovered toy placeholder. All surfaces stay in world space; no backdrop or fullscreen page is added.

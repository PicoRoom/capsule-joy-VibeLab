# 开壳与动物揭晓特效

目标：让玩家先期待、再看清动物、最后自然接手把玩。沿用陶瓷玩具的奶油金、海盐青、珊瑚粉和鸢尾蓝，所有特效位于胶囊周围的三维空间。

## 节奏

| 时段 | 表现 | 实现 |
| --- | --- | --- |
| 开壳 0–1.4 秒 | 12 枚星光旋转聚拢，逐渐变亮（视觉尺寸增加） | 跟随胶囊实际位置；与现有开壳音效、分壳动画同起 |
| 揭晓后 0–0.65 秒 | 动物从 35% 尺寸弹出，轻轻上浮，再回到原尺寸 | 最大约 6.5% 回弹；只改变显示子节点 |
| 揭晓后 0–1.81 秒 | 奶油金星芒向外舒展，彩纸上扬后飘落、缩小消失 | 重复款 24 个粒子，首次发现 36 个；额外星环延迟 0.22 秒出现 |
| 玩家拿起／收好 | 立即结束特效，模型回到正常尺寸 | 手势、库存和存档继续使用原有流程 |

三款机器共用同一个原生特效组件，不改抽取概率或制造稀有度。首次发现根据当前收藏历史判断，取出珍藏册中的旧玩具不播放揭晓特效。退出前台和观察内部会清理特效，不补播庆祝。

## 实现与边界

`RevealEffects.kt` 使用现有 PICO SDK 的 Entity、MeshResource 和 UnlitMaterial。36 个粒子节点与网格、材质初始化一次，后续复用；没有碰撞体、额外灯光、后处理、摄像机移动或全屏闪白。父级沿用立体窗口坐标。靠近窗口边缘时粒子可能被窗口裁切，玩具仍使用原有边界约束。

新揭晓动物的默认缩放值由 2 调为 6（原来的 3 倍），仍从最终尺寸的 35% 弹出。双手捏住后拉开／合拢使用 PICO 原生 transform 手势，尺寸范围统一为 0.8–12；单手移动也由同一个识别器处理。松手或拖回册子前保存位置与尺寸，取出后恢复。

`CapsuleScene.kt` 只在购买流程进入 REVEALED 时启动一次；暂停、收纳、再次购买均清理显示状态。模型弹出不改保存的姿态或用户操作层的缩放。

设计参考：任天堂在 [Super Mario Bros. Wonder 开发者访谈](https://www.nintendo.com/us/whatsnew/ask-the-developer-vol-11-super-mario-bros-wonder-part-2/) 中强调动画传达角色状态以及动作与乐器音效的配合。本项目采用清晰的阶段反馈与音画同步，具体星光、彩纸和时长为本项目设计。

## 验证

- 单元测试：弹出曲线的起止、回弹幅度，以及粒子显隐边界。
- 原生场景测试：三机型购买、开壳粒子、首次发现星环、自动结束、拿起中断、暂停清理、收纳、粒子池复用。
- 模拟器画面用于检查空间位置和可见性；头显内的实际尺度、帧率及双手操作舒适度需真机体验。

手势实现依据：[PICO SDK 6.1.9 detectSpatialTransformGesture](https://developer.picoxr.com/spatial-api/6.1.9/spatialui/foundation/com.pico.spatial.ui.foundation.gesture/detect-spatial-transform-gesture.html)，使用增量 scaleValue 累乘缩放。模拟器场景测试通过正式 transformToy 入口验证尺寸和存档，不冒充真机双手追踪测试。

## 双手掰开

取出胶囊后，统一球形抓取区域使用单个 PICO 双手变换识别器；单手移动整蛋，双手分离触发揭晓。任一手在触发前结束或取消，会复位半壳；暂停或切换观察模式也清理握持状态。

原有铰链翻盖路径与抓娃娃面板的一键开蛋入口已移除。自动开壳阶段两半向左右下方移开，玩具出现后蛋壳在 0.6 秒内缩小消失。玩具的操作层保持独立，可以立即拿取。

模拟器通过正式 beginHalf / moveHalf / endHalf 回调检查单手不触发、双手触发、中途释放复位及三机型完整购买流程；模拟器不能代替真机双手追踪验收。

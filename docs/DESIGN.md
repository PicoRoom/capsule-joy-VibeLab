# 原生应用结构

扭趣使用 PICO Spatial SDK 6.1.9 的 `DefaultWindowContainer` 运行于共享空间。透明立体窗口默认尺寸为 2.35 × 1.68 × 1.57 米，系统可限制实际尺寸；应用根据实际三维窗口尺寸拟合内容，金币、胶囊与玩具限制在窗口范围内。

## 模块责任

- `domain/model` 与 `domain/usecase`：购买阶段、库存、抓爪输入、距离判断和音效事件。
- `data/repository`：收藏实例、册内 ID、摆放、声音与教程完成记录的本机持久化。
- `scene`：模型加载、空间布局、碰撞、手势、运动、Portal 珍藏册及揭晓特效。
- `ui/capsule`：不可变 UI 状态、启动页、教程、系列选择与操作面板。
- `platform`：Android 入口、应用及窗口生命周期。

## 资源与交互

所有运行资源均位于 `app/src/main/assets/` 与 `app/src/main/res/`，Gradle 构建不生成模型或音频。三种机型各有外壳、内部机构与观察版本，三组动物每组六款。

系统控件移动整个窗口，薄荷横杆在窗口内微调；重置恢复居中。前两款投币后转柄出蛋，第三款通过摇杆或机器前方瞄准板控制抓爪，抓空消耗本轮硬币但不扣库存。胶囊使用统一双手识别器，单手移动、双手分离，中途松开复位。

六格珍藏册随系列显示动物；每次抽中增加一个真实实例，取出与归还只改变册内状态，不复制实例。玩具支持移动、旋转和缩放，操作后保存姿态。

## 启动与生命周期

标题、立体胶囊和开始入口组成启动页，设置替换标题胶囊。首次开始进入摆放、投币、转柄、取蛋、开蛋、收纳六步教程；步骤按真实玩法事件推进，完成状态独立保存。未完成轮次优先继续，教程跳过不清除轮次或收藏。

主菜单和内部观察暂停玩法；恢复后继续原进度。音频随前台与焦点恢复或暂停，不补播暂停期间的动作。退出关闭窗口。

## 验证范围

JVM 测试覆盖玩法、教程流程、动作曲线与音效事件；原生回归测试覆盖场景回调、布局、收藏、抓爪和教程。模拟器不能验证真实手追踪、舒适度和听感。

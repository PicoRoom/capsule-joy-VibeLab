# 原生应用结构

扭趣使用 PICO Spatial SDK 6.1.9 的 `DefaultWindowContainer` 运行于共享空间。透明立体窗口默认尺寸为 2.35 × 1.68 × 1.57 米，系统可限制实际尺寸；应用根据实际三维窗口尺寸拟合内容，金币、胶囊与玩具限制在窗口范围内。

## 模块责任

- `domain/model` 与 `domain/usecase`：购买阶段、库存、抓爪输入、距离判断和音效事件。
- `data/repository`：收藏实例、册内 ID、摆放、声音与教程完成记录的本机持久化。
- `scene`：模型加载、空间布局、碰撞、手势、运动、Portal 珍藏册及揭晓特效。
- `ui/capsule`：不可变 UI 状态、启动页、教程、系列选择与操作面板。
- `platform`：Android 入口、应用及窗口生命周期。

## 资源与交互

所有运行资源均位于 `app/src/main/assets/` 与 `app/src/main/res/`，Gradle 构建不生成模型或音频。三种机型各有外壳、内部机构与观察版本，三组动物每组六款。

系统控件移动整个窗口，薄荷横杆在窗口内微调；重置恢复居中。前两款投币后顺时针转柄出蛋。`CrankGesture` 累计绕轴有向角度，径向移动不计量，同次握持的反向回摆不重复累计；`CrankGuide` 在轴旁显示进度。第三款通过摇杆或机器前方瞄准板控制抓爪，抓空不扣库存，2.6 秒回到等待状态，并可保持落点直接重试。胶囊使用统一双手识别器，单手移动、双手分离；主动松开复位，取消追踪用单调时钟保留最多 300 毫秒。

六格珍藏册拥有独立于机器的翻页状态，显示本系列与总收藏进度；每次抽中增加一个真实实例，取出与归还只改变册内状态，不复制实例。玩具支持移动、旋转和缩放，操作后保存姿态。`CollectionDisplay` 定义展台位置，`CollectionShelf` 渲染底座；布置操作从真实收藏选择每种一只，原展台实例收回册内，不创建副本。拖拽到对应圆台附近自动归位，位置沿用收藏姿态持久化；重启从摆放位置恢复展台系列。

重复保护从按获取顺序保存的收藏记录计算，各系列独立计数，连续三次重复后选择未拥有款，重启不会清空保护。最后一款首次获得时展示完成文案、庆祝光环及金色展台；普通重复只提示当前数量。

`MechanismDemo` 仅驱动观察场景的实体与独立时钟，可播放一次或逐步查看，不向玩法状态机发送投币、抓取或揭晓事件。

## 启动与生命周期

动画数据文件在 IO 调度器读取和解析，避免阻塞主线程输入响应。标题、立体胶囊和开始入口组成启动页，设置替换标题胶囊。首次开始进入摆放、投币、转柄、取蛋、开蛋、收纳六步教程；步骤按真实玩法事件推进，完成状态独立保存。未完成轮次优先继续，教程跳过不清除轮次或收藏。

主菜单和内部观察暂停玩法；恢复后继续原进度。音频随前台与焦点恢复或暂停，不补播暂停期间的动作。退出关闭窗口。

## 验证范围

JVM 测试覆盖玩法、教程流程、动作曲线与音效事件；原生回归测试覆盖场景回调、布局、收藏、抓爪和教程。模拟器不能验证真实手追踪、舒适度和听感。
